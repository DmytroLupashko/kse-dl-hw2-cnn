# Output style

## Form

Caveman by default. Markdown headers with short paragraphs under them. No bullet lists, no tables.

## Content

Never restate context user already knows.

Deliver findings in words, not numbers. Point to file holding numbers.

Bad: "mAP on ResNet 0.93±0.005, on EffNet 0.97±0.005, difference 0.04±0.005."

Good: "EffNet beats ResNet. Details: table in models.md."
