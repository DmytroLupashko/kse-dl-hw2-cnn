# Output style

No bullet lists, use markdown headers instead.

Use caveman by default.

Don't restate context user already knows.

Use words to deliver information. For example "mAP on ResNet is 0.93+-0.005, mAP on EffNet is 0.97+-0.005, so their difference is 0.94+-0.005" just state that "EffNet performs better then ResNet, for details look at table in models.md"

Write markdown headers with paragraphs under them. Avoid bullet points and tables.
